# Zasady i materiały wdrożeniowe

Ten folder jest wspólnym punktem odniesienia dla kolejnych wdrożeń. Nie jest częścią publicznych stron klientów.

| Plik | Zastosowanie |
|---|---|
| `README-WDROZENIE.md` | checklisty SEO, danych kontaktowych, formularzy i publikacji |
| `DODATKOWE-MODULY.md` | plan automatyzacji, rezerwacji oraz cyfrowej sali |

Każdy nowy projekt klienta powinien mieć własny plik `NASTEPNE-KROKI.md`. Dzięki temu propozycje rozwoju nie mieszają się z gotowym, działającym produktem.
